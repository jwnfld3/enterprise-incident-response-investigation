# Enterprise Incident Response Investigation

This project simulates a real enterprise security investigation involving suspicious authentication activity detected in Microsoft Entra ID. The objective is to investigate the alert, analyze authentication logs, determine whether the activity represents an account compromise, and implement appropriate containment and remediation actions.

This lab demonstrates how identity related security incidents are investigated and documented in enterprise environments.

## Investigation Scenario

A security alert was triggered indicating unusual authentication activity for a user account. The alert suggested that a login attempt originated from an unfamiliar geographic location.

The objective of the investigation was to determine whether the activity represented a legitimate login attempt or a potential account compromise.

---

## Investigation Process

The investigation followed a structured workflow similar to incident response procedures used in enterprise IT security teams.

1. Review authentication logs  
2. Analyze login location and device information  
3. Verify user activity  
4. Determine risk level  
5. Implement containment measures  
6. Document findings and lessons learned
